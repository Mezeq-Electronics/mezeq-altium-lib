# Mezeq's Altium Library Repository

In this repository we'll be storing .SchLib, .PcbLib and .DbLib files. The first two are the files containing the information necessary for Altium to display schematic symbols and footprints, respectively, for components. Note that two, or more, distinct components, which differ by MPN, can be mapped to the same symbol and footprint.
